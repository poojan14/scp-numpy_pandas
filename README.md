# Scientific Python Lab – NumPy & Pandas

Interactive class website for *Scientific Computing using Python* (Poojan Shah, RRU), covering slides 1–48 of
**Scientific Python Packages** (NumPy part 2 and Pandas), plus extra Pandas manipulation, scenario practice and a final quiz.

- 27 lessons · 224 auto-checked coding tasks · 78 quick-check questions
- Real Python (NumPy + Pandas via Pyodide) runs in the browser – nothing to install
- Google sign-in, one-time registration with enrollment number, progress saved to Firebase
- Teacher dashboard (`dashboard.html`): class table, per-student code, task difficulty, CSV export

See **SETUP.md** for deployment.
